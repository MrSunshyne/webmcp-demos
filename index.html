webmcp demos

A set of small webmcp demos where you give instructions to your AI agent and it accomplishes the tasks for you. The pages register tools and WebMCP does the rest. Everything also works without any ai (you click around to interact)

To check before proceeding

  • Enable a Chrome Flag chrome://flags/#enable-webmcp-testing
  • Install the Chrome Extension WebMCP Model Context Tool Inspector
  • Add a Gemini API Key from aistudio.google.com
  • Serve locally with pnpx vite
  • DEMO 1: Dholl Puri Stand

    A roadside food stand. Your agent takes the order, you eat.

  • DEMO 2: Pixel Painter

    A 16×16 canvas. Ask for a heart, get a heart. Usually.

  • DEMO 3: Trip Splitter

    A shared trip tab. Your agent keeps score of who owes whom. Built with Vue and the vue-webmcp composable.
