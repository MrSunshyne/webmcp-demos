WebMCP Demos

Small experiments where the page registers tools for the AI agent living in your browser. Each demo works by hand too — the agent is optional, the tools are not.

  • 🫓 Dholl Puri Stand

    Order street food through imperative tools — menu, cart, checkout.

  • 🎨 Pixel Painter

    Ask the agent to draw on a 16×16 canvas with batched paint calls.

Requires Chrome with the WebMCP origin trial for the agent side — the WebMCP Model Context Tool Inspector extension is the easiest way to test.
